- 专利名称：一种非线性光子器件、制备方法、多值逻辑运算方法及其系统
## 📄 黑皮书
https://doi.org/10.5281/zenodo.22525745

## 🌟 核心技术要点
1. **纯电场调控机制**：避免热效应延迟，实现 GHz 至 THz 量级操作频率与超低静态功耗。
2. **亚波长表面等离激元局域**：计算单元缩至几百纳米量级，支持超高密度集成。
3. **突破二进制限制**：实现基于波长编码的多值逻辑与基于频率转换（和频/差频）的模拟四则算术运算。
4. **倒装模块化制造工艺**：解决二维材料异质集成良率瓶颈与环境稳定性封装。
5. **全球芯片物理指纹（Chip-DNA）公共库**：记录芯片微观物理缺陷，实现从底层硬件杜绝隐患;并且该物理缺陷可作为公钥实现物理不可克隆函数加密。
